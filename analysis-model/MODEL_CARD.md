# 유도 기술 추천 기준 모델 — 실행 결과

## 상태

2026-11-18에 실제 공개 영상으로 학습 및 평가를 완료한 **실험용 후보 추천 모델**이다.
독립 경기·새로운 선수에 대한 정확도는 검증하지 않았다. 사용자 확인이 필수이며
자동 판정이나 실서비스 정확도를 보장하지 않는다.

## 모델

- 가중치: `models/judo_r3d18.pt`
- 구조: 고정된 Kinetics-400 R3D-18 인코더 + 표준화 + 4종 선형 로지스틱 분류기
- 입력: 사용자가 선택한 30초 이내 단일 공격 구간의 균등 샘플 16프레임
- 출력: 상위 3개 기술 후보와 보정되지 않은 모델 점수
- 지원 라벨: `ippon_seoi_nage`, `o_goshi`, `osoto_gari`, `uchi_mata`
- 검증으로 선택한 분류기 정규화 설정: C=0.1
- 추론 시 외부 다운로드 불필요: 인코더와 분류기를 하나의 파일에 저장

## 데이터

원본 MP4 801개를 저장하고, 중복 66개와 프레임 읽기 검사 실패 59개를 제외했다.
676개를 학습 474 / 검증 101 / 평가 101로 분할했다.
자세한 제외 목록과 출처는 `data/audit.json`, `data/DATA_CARD.md`에 있다.

단순 기준은 학습 데이터의 최빈 기술 1개 또는 상위 3개 기술을 항상 추천하는 방식이다.

동일 배경·유사 영상·자막에 의존할 가능성과 제공자 라벨의 오류 가능성이 있다.
원 경기·선수 정보가 없어 정확 중복 제거만으로 원본 간 독립성이 보장되지는 않는다.

## 실행·검증

- CPU 4스레드, 최초 특징 추출과 학습·평가 약 409초 (프로세스 시작 시간 제외)
- 캐시된 676개 특징으로 재실행 시 약 11초, 동일 평가 수치 재현
- 사용자 득점 매핑·오입력·후보 순서·영상 시간 구간 처리 단위 테스트 4개 통과
- 저장 모델을 다시 로드하여 기술별 평가 표본 1개씩, 총 4개 추론 실행
- 저장 모델 출력과 학습 시 평가 출력의 일치 확인
- 분할 간 파일 SHA256 및 샘플 프레임 SHA256 중복 없음 확인
- 표본 추론은 첫 로드 포함 약 3.2초, 이후 약 0.9~1.1초: 4개 짧은 영상의 관측치이며 처리 시간 보장이 아님

표본 4개 중 2개는 1순위 기술을 잘못 추천했다. 실행 검증 통과는 분류 정답 보장이 아니라
저장 모델이 재현 가능하게 동작한다는 뜻이다. 정량 성능은 전체 평가 101개 결과를 사용한다.

## 자동화하지 않은 항목

착지 접촉·공격자·공식 득점·지원 외 기술 인식은 학습하지 않았다.
착지와 서비스 득점은 처음에는 `unreviewed`이며, 사용자가 확인한 값만 별도로 기록한다.
`unknown`과 `unreviewed`를 무득점으로 변환하지 않는다.

## 다음 개선에 필요한 데이터

전문가가 검수한 기술 라벨, 원본 영상·선수·경기 그룹 정보, 실제 사용 환경의 독립 평가
영상이 우선 필요하다. 자동 득점으로 확장하려면 착지 구간과 접촉 유형 정답을 추가해야 한다.

## 결과 파일

- `data/evaluation.json`: 설정 선택·성능·혼동 행렬·클래스별 지표
- `data/test_predictions.json`: 평가 영상별 예측
- `data/smoke_check.json`: 저장 모델 재실행 검증
- `runs/example_*.json`: 기술별 표본 추론 결과

원본 영상 권리 관계는 제공자 MIT 표기만으로 확인되지 않는다. 데이터와 가중치는 로컬
실험용으로 보관하며 Git에 포함하지 않는다. 원본 영상 재배포 및 제품 배포 전 사용 조건을 확인해야 한다.
