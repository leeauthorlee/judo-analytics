> 아래 기능 표는 초기 전체 목표입니다. 현재 구현 범위는 [축소 PRD](../../PRD-judo-analysis-mvp.md) 및 [모델 연결 현황](../architecture/model-integration.md)이 우선합니다. 30초 이내 사용자 지정 구간의 기술 후보 추천과 사용자 착지 확인을 연결했으며, 자동 관절·득점·선수 역할 분석은 제외합니다.

## 공통

| 주요 기능 | 분류 | 상세기능 | Description |
|---|---|---|---|
| 이용자 접근 | 계정 | Google 로그인 | 사용자는 Google OAuth 인증을 통해 회원으로 로그인한다. |
| 이용자 접근 | 계정 | Kakao 로그인 | 사용자는 Kakao OAuth 인증을 통해 회원으로 로그인한다. |
| 이용자 접근 | 계정 | Naver 로그인 | 사용자는 Naver OAuth 인증을 통해 회원으로 로그인한다. |
| 이용자 접근 | 계정 | 로그아웃 | 사용자는 현재 로그인/세션을 종료한다. 종료 후 인증이 필요한 API 접근은 거부된다. |
| 비회원 이용 | 세션 | 게스트 세션 생성 | 로그인하지 않은 이용자가 서비스에 진입하면 익명 세션과 전용 Workspace를 생성한다. |
| 데이터 관리 | 권한 | Workspace 데이터 격리 | 영상, 분석 결과, 하이라이트, 일기는 회원 계정 또는 해당 게스트 세션의 Workspace에 귀속한다. 다른 Workspace의 자료는 접근할 수 없다. |
| 영상 관리 | 업로드 | MP4 업로드 | 사용자는 분석할 최대 500 MB, 10분 이하의 MP4 영상을 선택하거나 끌어 놓아 업로드한다. |
| 영상 관리 | 검증 | 업로드 파일 검증 | 서버는 파일 시그니처/컨테이너와 메타데이터를 확인하고, 미지원·손상·크기 또는 10분 제한 초과 영상은 분석 큐에 넣지 않고 이유를 안내한다. |
| 영상 관리 | 보관 | 비공개 저장 | 원본과 파생 영상 파일은 비공개 객체 스토리지에 저장하고, 접근 권한을 확인한 후에만 재생 가능한 URL을 발급한다. |
| 영상 관리 | 목록 | 영상 목록 조회 | 사용자는 본인 Workspace에 속한 영상의 이름, 업로드일, 길이, 상태 및 분석 여부를 조회한다. |
| 영상 관리 | 삭제 | 영상 삭제 | 사용자가 삭제를 요청하면 원본, 썸네일, 관절 파일, 연결된 분석 자료 등 정책에 해당하는 파생 데이터를 삭제 또는 보존 정책에 따라 처리한다. |
| 개인정보 | 고지 | AI 판정 안내 | 분석 결과 화면에는 AI 추정이며 공식 심판 판정이 아니라는 안내를 표시한다. |

## 회원

| 주요 기능 | 분류 | 상세기능 | Description |
|---|---|---|---|
| 계정 관리 | 프로필 | 회원 정보 조회 | 회원은 본인의 표시 이름 및 연결된 로그인 공급자 정보를 확인한다. |
| 영상 분석 | 영상 선택 | 저장 영상 분석 요청 | 회원은 본인이 업로드한 영상 중 하나를 선택해 분석을 요청한다. 요청에는 영상, 적용 규정, 분석 모델 버전이 연결된다. |
| 분석 결과 | 이력 | 과거 분석 조회 | 회원은 저장 영상의 과거 분석과 사용된 모델/규정 버전을 조회할 수 있다. |
| 하이라이트 | 보관 | 하이라이트 목록 | 회원은 분석에서 생성했거나 직접 지정한 하이라이트를 본인 Workspace에서 확인한다. |
| 일기 | 기록 | 날짜별 일기 작성 | 회원은 날짜별 제목과 메모를 작성하고 본인 하이라이트를 연결한다. 하이라이트는 하나의 일기에만 연결한다. |
| 일기 | 조회 | 일기 타임라인 | 회원은 날짜순으로 일기와 연결된 하이라이트를 조회한다. |

## 비회원

| 주요 기능 | 분류 | 상세기능 | Description |
|---|---|---|---|
| 게스트 세션 | 데이터 보존 | 세션 내 기록 유지 | 비회원은 브라우저 세션이 유지되는 동안 같은 게스트 Workspace의 영상·분석·하이라이트·일기를 다시 확인한다. |
| 게스트 세션 | 만료 | 세션 종료 처리 | 브라우저 세션 종료 후 접근을 종료한다. 서버의 물리 삭제 시점과 유예 기간은 보존 정책에서 정한다. |
| 영상 분석 | 요청 | 세션 영상 분석 | 비회원도 본인 게스트 Workspace에 올린 영상에 대해 회원과 동일한 분석 흐름을 요청할 수 있다. |
| 일기 | 기록 | 세션 일기 작성 | 비회원은 세션 중 날짜별 기록과 하이라이트를 저장할 수 있다. 하이라이트는 하나의 일기에만 연결하며 세션을 벗어난 데이터 이전/복구는 MVP 범위에서 제외한다. |

## 영상 분석

| 주요 기능 | 분류 | 상세기능 | Description |
|---|---|---|---|
| 분석 처리 | 작업 생성 | 분석 작업 등록 | 시스템은 분석 요청을 영속 작업으로 등록하고 작업 ID를 반환한다. 분석은 업로드 HTTP 요청과 분리된 백그라운드 처리로 실행한다. |
| 분석 처리 | 상태 | 진행 상태 조회 | 사용자는 대기, 처리 중, 검토 필요, 완료, 실패 상태를 확인한다. 실패에는 재시도 가능 여부와 사용자용 원인을 표시한다. |
| 관절 분석 | 자세 추출 | 관절 시계열 생성 | 분석 워커는 영상에서 익명 선수 트랙과 시간 정보가 있는 관절/자세 시계열을 추출해 버전이 명시된 artifact로 저장한다. |
| 기술 분석 | 기술 분류 | 이벤트 및 기술 후보 | 시스템은 기술 시도 구간의 시작/끝 시각과 기술명을 추정한다. 식별이 불가능하면 `판별 불가`로 반환한다. |
| 판정 분석 | 이벤트 점수 | 기술별 점수 후보 | 시스템은 각 기술 이벤트에 대해 적용 규정 버전 기준의 점수 후보(한판, 절반, 유효, 무득점, 불확실 등)를 제공한다. MVP는 최종 승패를 산출하지 않는다. |
| 판정 분석 | 근거 | 증거 및 누락 정보 | 결과는 이벤트 타임스탬프, 관찰된 근거, 가림/누락 정보, 신뢰 구간을 포함한다. 영상으로 근거가 부족하면 점수를 단정하지 않고 불확실로 둔다. |
| 판정 분석 | 규정 | 규정 버전 표시 | 분석 결과는 사용 규정의 이름과 버전을 표시한다. 규정이 미지원/미확인인 경우 지원되지 않음을 안내한다. |
| 모델 연동 | 버전 | 모델 버전 추적 | 분석 작업마다 모델 식별자/버전과 결과를 기록해 재현 및 비교할 수 있게 한다. 모델이 미연결이면 판정을 생성하지 않고 설정 오류를 안내한다. |
| 검토 | 정정 | 운영자 결과 검토 | 학습 운영자는 분석 이벤트/점수 후보를 검토하고 검토 상태 또는 정정 결과를 기록한다. 운영자 도메인 자격 기준은 미확정이다. |

## 학습 데이터 및 모델 운영

| 주요 기능 | 분류 | 상세기능 | Description |
|---|---|---|---|
| 후보 탐색 | YouTube 메타데이터 | 검색 결과 목록 | 운영자는 초기 후보 탐색을 위해 공식 YouTube Data API를 사용해 검색어(예: 유도 올림픽)에 대한 영상 ID, 제목, 채널, 게시일, URL 등의 메타데이터를 확인한다. |
| 후보 탐색 | 사용 제한 | 영상 파일 취득 금지 | 메타데이터 조회만으로 영상 사용/학습 권리가 생기지 않는다. 권리 허가가 확인되기 전에는 영상 스트림/파일 다운로드, 프레임 추출, 전사 내용 복사 및 학습 등록을 하지 않는다. |
| 권리 관리 | 라이선스 | 영상 사용 권리 등록 | 운영자는 권리자, 허가 문서, 지역, 사용 기간, 학습/클라우드 전송 허용 여부를 기록한다. 허가 상태가 승인되지 않은 영상은 학습 대상으로 등록할 수 없다. |
| 데이터셋 | 구성 | 학습 샘플 등록 | 운영자는 승인된 영상 구간과 관절 artifact를 데이터셋 버전에 등록한다. 각 샘플은 원본 경기, 시간 구간, 규정, 권리 근거와 연결한다. |
| 데이터셋 | 분할 | 데이터 분리 | 샘플은 train/validation/test로 구분하며 같은 경기 또는 동일 원본의 인접 클립이 서로 다른 분할에 섞이지 않게 한다. |
| 라벨 | 어노테이션 | 기술/판정 라벨 입력 | 운영자는 기술 종류, 이벤트 시간, 적용 규정, 점수 라벨 및 관찰 근거를 입력/검토한다. 라벨에는 출처와 검토 상태를 보존한다. |
| 라벨 | 약한 라벨 | 제목/해설 참고 | 제목·해설·전사 텍스트는 라벨 후보나 검색 근거로만 사용한다. 전문가 검토 전에는 정답 라벨로 학습/최종 평가에 사용하지 않는다. |
| 학습 | 실행 | 모델 학습 작업 | 운영자는 고정된 데이터셋/초기 모델/코드 revision/파라미터를 사용해 별도 학습 워커에서 학습을 실행한다. 진행 상태와 오류를 기록한다. |
| 학습 | 평가 | 검증 지표 | 학습 결과는 검증/시험 데이터 기준 기술별 성능, 점수별 오탐, 이벤트 구간 오차, 불확실 판정 비율 및 주요 실패 유형을 기록한다. |
| 모델 관리 | 배포 | 검증 모델 활성화 | 운영자는 승인된 모델 버전을 분석 서비스에 배포/활성화한다. 배포 전 버전은 일반 분석 결과를 생성하지 않는다. 모델 교체 후에도 과거 결과의 사용 버전은 유지한다. |
| 서비스 보호 | 남용 방지 | 공개 서비스 사용량 제한 | 일반 공개 서비스이므로 사용자/게스트별 업로드·분석 quota와 요청 속도 제한을 적용하고, 초과 시 안내한다. 세부 quota와 abuse 대응 기준은 운영 정책에서 정한다. |

## 하이라이트 및 일기

| 주요 기능 | 분류 | 상세기능 | Description |
|---|---|---|---|
| 하이라이트 | 자동 후보 | 분석 이벤트 하이라이트 | 사용자는 분석 이벤트의 시간 구간을 하이라이트로 저장할 수 있다. 시스템은 이벤트의 시작/끝 시각을 기본 구간으로 제안한다. |
| 하이라이트 | 직접 지정 | 구간 편집/추가 | 사용자는 영상 플레이어에서 시작/끝 시각을 선택해 수동 하이라이트를 만들거나 구간을 편집한다. |
| 하이라이트 | 목록 | 클립 재생 및 관리 | 사용자는 제목/메모/썸네일과 함께 하이라이트를 재생, 조회, 삭제할 수 있다. |
| 일기 | 작성 | 날짜별 기록 작성 | 사용자는 날짜, 제목, 메모를 입력하고 하이라이트를 일기 항목에 연결한다. 하이라이트는 하나의 일기에만 연결한다. |
| 일기 | 조회 | 날짜순 기록 | 사용자는 일기와 연결된 하이라이트를 날짜순으로 조회한다. 빈 날짜 표시/검색/태그 기능은 범위 미확정이다. |

## 현재 구현 상태

- **기존 코드 확인:** Supabase Google/Kakao 로그인, 회원 Workspace/RLS, Blob 업로드, 영상 삭제, Cloud Tasks 워커, 하이라이트·일기 API.
- **이번 연결:** 사용자 공격 구간 지정 → 워커의 Python R3D-18 호출 → 4종 중 상위 3개 기술 후보 표시 → 사용자 기술·착지 확인. 실제 완료 결과로 하이라이트·일기를 저장하며 모델 예측과 사용자 확인값을 분리한다.
- **적용 조건:** 새 DB 마이그레이션, 모델 포함 워커 배포, Blob·Cloud Tasks·서비스 역할 환경변수. 로컬 실모델 호출과 클라우드 전체 경로 검증은 구분한다.
- **미구현/제외:** Naver·게스트, 자동 관절·역할·득점 분석, 운영자 학습 관리 UI, 자연어 대화형 챗봇.
- YouTube Data API 연동은 구현되지 않았으며, 연동 시에도 본 명세서상 초기 기능은 메타데이터 후보 검색만 의미한다.

## 미확정 사항 / 확인 질문

1. **운영자 자격:** 운영자가 라벨 검토와 학습 관리를 함께 맡는 것으로 반영했습니다. 해당 운영자는 유도 심판/지도자 자격을 갖춘 검수자여야 하나요?
2. **일기 UX:** 빈 날짜 표시, 검색/태그, 분석이 없어도 일기 작성하기가 필요한가요?
3. **성능 목표:** 10분 영상을 몇 분 이내에 분석 완료해야 하는지 목표 SLA를 정할까요?
