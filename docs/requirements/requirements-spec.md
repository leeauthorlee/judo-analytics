## 1. 목적 및 범위

회원 또는 비회원이 유도 경기 영상을 관리하고, 영상 분석 모델이 기술 후보와 점수 판단 근거를 제공하며, 사용자가 하이라이트를 일기 형태로 기록할 수 있는 서비스를 제공한다. 권리 확인 및 전문가 라벨링이 된 유도 영상과 관절 시계열을 이용해 학습 데이터셋을 구성하고, 학습 실행 및 모델 버전을 관리한다.

### 1.1 대상 범위

- Google, Kakao, Naver OAuth 회원 로그인
- 회원 및 비회원 세션별 영상·분석·하이라이트·일기 데이터 관리
- MP4 업로드와 영상 메타데이터 관리
- 관절/자세 추출, 유도 기술 분류 및 점수 후보 분석
- 기술 장면 하이라이트 저장 및 일기 기록
- 사용 권리가 확인된 영상으로 학습 데이터 구성, 라벨 검토, 모델 학습 및 버전 관리
- Next.js 기반 웹 앱과 Vercel 배포, 장시간 GPU/영상 처리는 별도 워커 연계

### 1.2 범위 밖 또는 별도 승인 필요

- AI 결과를 공식 경기 판정으로 표시하거나 심판을 대체하는 기능
- 얼굴 인식, 실명 식별 또는 선수 신원 추정
- 권리자의 허가가 확인되지 않은 YouTube/올림픽 영상의 다운로드·프레임 추출·학습 사용
- 학습되지 않은 모델이 판정을 생성하는 것처럼 표시하는 기능
- 실시간 경기 스트림 분석(별도 요구사항으로 정의 필요)

## 2. 사용자 및 권한

| 사용자 유형 | 설명 | 주요 권한 |
|---|---|---|
| 비회원 | OAuth 가입 없이 임시 세션으로 이용 | 본인 게스트 세션의 영상·분석·일기 조회/관리 |
| 회원 | Google, Kakao 또는 Naver로 인증 | 본인 워크스페이스의 영상·분석·일기 관리 |
| 학습 운영자 | 데이터셋·학습 작업을 관리하는 운영 담당자 | 권리 확인, 라벨 검토, 학습 실행 및 모델 배포 관리 |

회원과 비회원 데이터는 `Workspace`를 소유 경계로 분리한다. 모든 API는 요청한 사용자가 대상 Workspace의 소유자/승인 사용자임을 서버에서 확인한다. 운영자의 유도 도메인 검수 자격은 추가 확인이 필요하다.

¹ 위 상세 표의 개발 상태는 초기 초안 시점 기록입니다. 현재 상태는 문서 상단의 적용 요구사항 및 모델 연결 현황을 참고합니다. Google/Kakao·회원 RLS·영상 검증/삭제·큐·워커·일기 코드는 이미 있으며, 모델 연결은 이번 수정으로 추가했습니다. 실제 클라우드 동작은 환경 설정 후 별도 확인이 필요합니다.

## 5. 외부 연동 및 제약

- **로그인:** Google, Kakao, Naver OAuth. 각 공급자의 앱 등록, redirect URI, 동의 범위 및 검수 요건이 선행되어야 합니다.
- **스토리지:** Vercel Blob private 또는 대체 private object storage. 업로드 제한과 비용은 운영 계획에 맞춰 확정해야 합니다.
- **모델 추론:** Next.js API는 제어/상태 API 역할을 하고, GPU 기반 긴 영상 분석은 별도 워커/서비스에서 처리하는 것을 기본안으로 합니다.
- **학습:** 모델 학습 파이프라인은 웹 서버와 분리합니다. 학습/검증/시험 데이터는 권리 확인되고 전문가 검토된 자료만 포함합니다.
- **YouTube/올림픽 영상:** 초기에는 공식 YouTube Data API의 검색 메타데이터로 후보만 목록화합니다. 공개/임베드 가능 여부는 다운로드·프레임 추출·학습 권리를 의미하지 않으며, 별도 권리 허가 전에는 영상 파일을 가져오지 않습니다.

## 6. 미확정 사항 및 확인 질문

아래 항목은 이 초안에서 임의 확정하지 않았습니다. 답변에 따라 요구사항과 ERD를 갱신해야 합니다.

1. **규정 버전:** 초기 범위는 IJF 시니어 최신 규정입니다. 실제 적용할 판본/시행일 및 대회 범위 확정이 필요합니다.
2. **분석 SLA:** 10분 영상의 최대 분석 완료 시간을 정해야 합니다.
3. **일기 UX:** 빈 날짜 표시, 검색/태그 및 분석이 없어도 일기를 작성하는 기능이 필요한가요?
4. **운영자 자격:** 단일 운영자가 학습 관리와 라벨 검토를 맡는 것으로 반영했습니다. 유도 심판/지도자 자격이 필요한가요?
